# Apps — the things people actually see

Built from the markdown in `company/`, `customers/`, `brand/` and `departments/`. If an app and a markdown file disagree, the markdown wins: fix the doc, then rebuild the app.

| Folder | Built in | Plan lives in |
|---|---|---|
| `website/` | Round 4 | `departments/marketing/website.md` |
| `course/` | Round 5 (if the product is a course) | `departments/content/curriculum.md` |

Lead magnet pages live next to their plans in `departments/marketing/lead-magnets/`.

All plain HTML/CSS/JS. Open the `index.html` in a browser to see it.
